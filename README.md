# Hi, I'm Zoi 👋

I'm a statistician and data analyst with more than ten years of experience. My job, as I see it: take messy numbers, make them trustworthy, then explain them so a busy person gets it in ten seconds.

## What I care about

- **Getting the numbers right first.** Clear definitions, honest sources, and a plain note on what the data can't tell you.
- **Looking at who's behind the average.** I split results by sex, age, country or income whenever it matters, because averages hide people.
- **Making it repeatable.** If I can't rerun it next month with one command, I'm not done.
- **Telling the story.** A good chart saves the reader a page of text.

## How I work

1. I start with the question, not the chart.
2. I write down where the data came from and how it was defined.
3. I check the groups: who is counted, who is missing, and how the numbers differ for women and men, young and old.
4. I make the chart simple enough to read without me in the room.
5. I share the code so anyone can check it.
